# HorizonTechX Internship Projects

This repository contains the projects completed as part of my Horizon TechX Internship.

## Completed Tasks

### Task 3 - Data Analysis & EDA
Performed exploratory data analysis using Python and Pandas. Analyzed student marks and attendance, calculated statistics, checked missing values, and identified relationships in the dataset.

### Task 4 - Data Visualization Dashboard
Created an interactive-style Student Performance Dashboard using Python and Matplotlib. The dashboard includes KPI metrics, marks analysis, attendance analysis, attendance vs marks, and performance distribution.

### Task 6 - Sentiment Analysis
Built a basic sentiment analysis model using Python, CountVectorizer, and Logistic Regression to classify text reviews into Positive, Negative, and Neutral sentiments.
